\# BMU Unity Practical — Set A



A 3D Unity project developed for the \*\*Unity \& AR/VR Development\*\* course at BML Munjal University.



\## Project Overview



This project demonstrates Unity scene architecture, physics components, player movement, trigger-based interactions, collectible scoring, and hazard-based respawning.



\## Features



\- \*\*Player Movement:\*\* Horizontal and vertical movement using Unity input axes.

\- \*\*Physics System:\*\* Rigidbody and collider-based interactions.

\- \*\*Collectibles:\*\* Trigger detection, item destruction, and score tracking.

\- \*\*Hazard Zone:\*\* Detects player contact and supports respawning at a safe location.

\- \*\*Spawn Point:\*\* Defines the player's respawn position.

\- \*\*Materials:\*\* Visual distinction between the ground, player, collectibles, and hazard zone.

\## Getting Started



1\. Clone or download this repository.

2\. Open Unity Hub.

3\. Select \*\*Add Project from Disk\*\* and choose the project folder.

4\. Use the Unity Editor version specified in `ProjectSettings/ProjectVersion.txt`.

5\. Open the appropriate gameplay scene and press \*\*Play\*\*.



\## Controls



\- \*\*W / S:\*\* Move forward or backward.

\- \*\*A / D:\*\* Move left or right.

\- \*\*Arrow Keys:\*\* Movement, if configured in the project.



Controls depend on the project's input configuration.
